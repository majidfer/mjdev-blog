## Bikin Blog dengan Template AstroJS

### Mulai dari Nol? Gak Perlu

Jujur aja, bikin blog dari nol itu capek. Setup layout, styling, SEO, belum lagi performance. Kadang belum nulis satu artikel pun, energinya udah habis duluan.

Makanya gue pilih jalan yang lebih praktis: pakai template dari AstroJS.

Dengan approach ini, kita bisa langsung fokus ke yang penting — nulis dan publish.

### Kenapa AstroJS?

AstroJS itu bukan sekadar framework biasa. Dia didesain untuk bikin website yang:

- Super cepat (karena static-first)
- Minim JavaScript di client
- SEO friendly out of the box
- Fleksibel (bisa pakai React, Vue, atau tanpa framework sama sekali)

Buat blog? Perfect banget.

## Setup Awal (Gak Sampai 10 Menit)

Dengan template yang tepat, prosesnya simpel:

1. Clone atau download template
2. Install dependency
3. Jalankan project

Contoh:

```bash
pnpm install
pnpm run dev
```
